# Daniel Lawal — Developer Portfolio

My personal developer portfolio showcasing my projects, skills, experience, and contact information.

🌐 **Live Website:** https://daniel-portfolio-v2-iota.vercel.app

## ✨ About

This portfolio was built to showcase my work as a Computer Science student and web developer.

It focuses on a clean, interactive experience with smooth animations, responsive layouts, project showcases, and a functional contact form.

## 🚀 Features

- Responsive design for desktop, tablet, and mobile
- Animated hero section
- Scroll-triggered section animations
- Projects showcase
- Skills section
- Experience timeline
- Contact form
- Resend-powered email delivery
- Reduced-motion accessibility support
- Direct navigation to page sections
- Custom cursor interactions

## 🛠️ Built With

- React
- JavaScript
- Vite
- Tailwind CSS
- GSAP
- Lucide React
- Resend
- Vercel
